# MERN News App

A full-stack MERN application that scrapes top stories from Hacker News.

## Features

- Hacker News Scraper
- JWT Authentication
- Bookmark Stories
- Protected Routes
- React Frontend
- MongoDB Database

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB

## Run Backend

cd backend
npm install
npm run dev

## Run Frontend

cd frontend
npm install
npm run dev

## Environment Variables

PORT=5000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret
